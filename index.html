業務自動化 / API連携

APIとAIを組み込んだ
業務自動化システムをつくります

椎名澪です。Python と Google Apps Script を使って、手作業で繰り返している業務を 自動で回る仕組みに置き換える開発をしています。 外部APIの連携、AIの組み込み、サーバーでの定期実行まで一貫して構築します。

ご相談いただける内容

「毎回この作業を手でやっている」という状態を、動く仕組みに変えるところが専門です。

スプレッドシート × AI

Google スプレッドシートの内容をAIに処理させ、要約・分類・下書き生成などを自動化します。ボタン一つで動く形にします。

API連携・データ収集

複数のサービスをAPIでつなぎ、データの取得・加工・転記を自動化します。OAuth認証を伴うものにも対応します。

定期実行の仕組みづくり

cron / launchd / トリガーによる無人実行の設計。認証の期限切れや、止まったことに気づけない問題への対策まで含めて組みます。

WordPress の運用自動化

REST API を使った投稿・更新の自動化。テーマの制約はプラグインを自作して回避します。

制作実績

自社メディアの運用のために設計・実装し、実際に運用しているシステムです。ソースコードは全文公開しています。

検索データの週次レポート自動生成システム稼働中

Google Search Console のデータを毎週自動で取得し、 「どの記事を直せば成果が出るか」「まだ書いていない需要はどこか」を 判断できる形にまとめて出力するシステムです。

launchd（毎週月曜 8:00・スリープ時は起動後に補完実行）
 └ 上位クエリの抽出 ／ 前週との順位比較 ／ 改善対象記事の抽出 ／ 新規テーマの候補抽出
    └ 1つのレポートに統合してファイル出力 ＋ 完了通知

  • OAuthの認証が2回失効しましたが、その都度検知して復旧させています。納品して終わりではなく、動き続ける状態を保つところまでを含めて経験しています。
  • データを出すだけでなく、判断できる形に変換しています。「検索順位30〜100位の記事＝あと一押しで1ページ目に届く」「表示はあるがクリックが0のクエリ＝需要はあるのに記事がない領域」といった条件で切り出しています。
  • 一度、7週間止めてしまいました。その原因を特定して直しています。cron で組んでいた当初、月曜8時にMacがスリープしていると実行時刻が破棄され、ログも残らないため停止に気づけませんでした。macOS 標準の launchd に移行し、スリープで取りこぼした実行を起動時に補完する設定と、失敗が必ずログに残る設定を追加して解決しています。「動かなくなったことに気づけない」状態を作らないことが、定期実行では一番重要だと考えています。

WordPress 運用ツール群

記事の投稿・更新・インデックス申請を、管理画面を開かずコマンドから実行できるようにしたツール群です。

WordPress REST API 連携アプリケーションパスワードによる認証で、記事の投稿・更新を自動化
Claude API 連携既存記事の本文を取得してAIで書き直し、WordPress に反映
Google Indexing API公開したURLのインデックス申請
環境差分の吸収開発機（macOS）と本番サーバーでディレクトリ構成が異なる問題に対し、候補パスを順に評価して最初に存在したものを採用する仕組みを実装

WordPress プラグインの自作

使用中のテーマのSEO設定項目が REST API から読み書きできず、外部から自動更新できない問題がありました。 テーマ本体を改造すると更新時に消えてしまうため、プラグイン側で解決しています。

実装register_post_meta() で対象のメタ項目を REST API に公開。auth_callback に編集権限のチェックを設定し、権限のないアクセスを遮断
運用本番サイトで有効化して使用
言語PHP
